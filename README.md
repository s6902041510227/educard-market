# EduCard Market — ตลาดการ์ดความรู้

ตลาดแลกเปลี่ยน **การ์ดความรู้** ที่นักศึกษาและอาจารย์ออกแบบสร้างขึ้นเอง — ส่งเสริมการเรียนรู้แบบ Peer-to-Peer Learning และฝึกทักษะการสรุปจับใจความ (Instructional Design)

## ฟีเจอร์

- **Header & Navigation** — ชื่อร้าน, ค้นหาชื่อการ์ด, เมนูเลือกวิชา (วิทยาศาสตร์, คณิตศาสตร์, ภาษาอังกฤษ, ประวัติศาสตร์, ภูมิศาสตร์, ชีววิทยา)
- **Filter** — กรองตามระดับชั้น (ป.1–3, ป.4–6, ม.1–3, ม.4–6), ประเภทการ์ด (สรุปบทเรียน, คำศัพท์, สูตร/ตาราง, ไทม์ไลน์, คำถามท้ายบท), และการ์ดฟรี
- **Card Grid** — แสดงการ์ดพร้อมรูปภาพ, ชื่อ, ผู้สร้าง, ราคา (บาท), ปุ่มดูรายละเอียด
- **Card Detail Modal** — รูปขยาย, จุดประสงค์การเรียนรู้, ผู้สร้าง, สต็อก, ปุ่มติดต่อผ่าน Line
- **Admin Panel** — เพิ่มการ์ดใหม่ (ชื่อ, วิชา, ระดับชั้น, ประเภท, ผู้สร้าง, ราคา) อัปเดตหน้าเว็บทันที
- **Dark Mode Modern** — รองรับ Responsive design ทุกอุปกรณ์

## เทคโนโลยี

- HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript
- ไม่ต้อง build — เปิดไฟล์ `index.html` ได้เลย
